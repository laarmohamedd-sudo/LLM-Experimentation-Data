This study provides a structural identification of what I define as a reference-point activation protocol. Using a dataset of 1,422 observations (See the original Data jstor files ), I show that deviations from the Nash equilibrium are not random but systematically gravitate toward salient reference points. To strengthen the robustness of the analysis, I incorporate the dataset from Mei et al. (2024), covering 88,595 human subjects, along with benchmark comparisons using GPT-4 and GPT-3.5.
